# Fonts (self-hosted)

Bricolage Grotesque and Figtree, variable weight, Latin subset (covers English and Spanish). Both use the SIL Open Font License 1.1 (see the `OFL-*.txt` files). Taken from the `@fontsource-variable/*` 5.3.0 packages.

They live in the repository so builds never depend on downloading fonts from Google, which once broke CI. Visitors' browsers never contact Google either.
